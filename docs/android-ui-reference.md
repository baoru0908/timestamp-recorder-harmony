# Android 原版最终 UI 布局参考（供鸿蒙 P3 UI 对齐）

> 来源：2026-09-15 用 AVD `tsr_api36`（原生 Android 16 / API 36，1440×3200，density 522）运行
> `D:\AI\TimestampRecorder`（app-debug.apk）逐页实测：截图 + uiautomator dump + 布局源码核对。
> 用途：鸿蒙版 UI 开发（P3）按本文件对齐，保证两版「几乎一样」方便统一教程。
> 注意：截图中显示深色主题（AVD 系统为深色模式），Android 版**跟随系统深浅色**。

## 0. 全局

- 主题：Material3，**跟随系统深浅色**；主背景为渐变（`bg_main_gradient`，深色下为蓝黑渐变）。
- 玻璃效果：顶部 AppBar / 底部 Tab 栏都是**液态玻璃**（LiquidGlassView：实时折射 + 色散 + 模糊下方内容），AppBar 透明叠在玻璃上，滚动时内容从玻璃底下穿过。
- 事件行卡片：MaterialCardView，圆角 20dp，玻璃卡背景 + 1dp 玻璃描边（`glass_card` / `glass_stroke`），无阴影。
- 状态栏：沉浸式（内容顶到状态栏下方）。

## 1. 主页（MainActivity）

```
┌──────────────────────────────────────┐
│ 时间戳记录                    ⋮      │ ← 大标题(约22sp bold) + 右上「更多」44dp
│ 管理事件 · 一键记录 · 桌面快捷        │ ← 副标题小字(约13sp, 次要色)
│ ┌─玻璃卡片─────────────────────────┐ │
│ │≡ ● e2             ⋮   [+1]      │ │ ← 每行: 拖拽柄32×36 / 色点14dp / 名称17sp bold / 最近时间 / ⋮ / 记录胶囊按钮
│ │  最近 20:56:10                   │ │
│ └──────────────────────────────────┘ │
│  …（多行）                           │
│                                      │
│        [事件]  (＋)  [时间线]        │ ← 底部玻璃栏: 左Tab「事件」+ 中央FAB「＋」+ 右Tab「时间线」
└──────────────────────────────────────┘
```

- 事件行三图标（content-desc）：`拖拽排序`（左侧手柄，仅手动模式显示）/ `更多操作`（行内 ⋮）/ `记录一次`（右侧 +N 胶囊按钮，蓝底白字，含计数）。
- 记录按钮文案：`+ 1` / `+ 2`（数字 = 当前累计次数，点击 +1）。
- FAB「＋」：位置可在设置切换（左/中/右，默认中），悬浮于底部栏上方；「添加事件」。
- 行内 ⋮ 菜单：编辑 / 删除（长按行也可拖拽排序）。
- 顶部 ⋮ 弹窗（右上玻璃弹窗，约 300dp 宽、右对齐）：`设置` / `统计` / `使用教程`，每行带图标。

## 2. 时间线 Tab

```
2026年9月 · 12条          ← 月头: 左侧色线 + 「YYYY年M月 · N条」
│ ● e2   2026-09-14 20:56   8小时,59分钟前
│ ● e1   2026-09-14 20:56   8小时,59分钟前
│ ● e10  2026-09-14 17:23   12小时,32分钟前
```

- 左侧 2dp 竖线贯穿整列（`timeline_track`），线从月头线开始。
- 每条记录：色点 + 事件名(约15sp bold) + 具体时间 `YYYY-MM-DD HH:mm`(次要色) + 右侧相对时间（`8小时,59分钟前` 等，与 Android TimeFormat.relative 一致）。
- 底部同样玻璃栏（事件 / ＋ / 时间线）。

## 3. 事件详情页（EventDetailActivity）

```
← e2                ☑ ⋮      ← 返回 + 事件名 + 完成勾选 + 更多
┌────────────────────────┐
│  ⏱ 记录此刻             │ ← 超大圆角按钮(事件主色，高约 64dp 横贯，左侧时钟图标)
└────────────────────────┘
共 1 条 · 最近 20:56:10
撤销上一条                      ← 蓝色文字链接
┌ #1  2026-09-14 20:56:10 │
│     Unix 秒：1789419370  │  复制
└─────────────────────────┘
```

- **背景 = 事件色渐变**（深紫渐变示例；事件色向深色过渡）。
- 记录按钮「记录此刻」：事件主色 + 白色文字 + 时钟图标。
- 记录卡片：`#序号`(主题色) + `完整时间 YYYY-MM-DD HH:mm:ss`(等宽) + `Unix 秒：<毫秒/1000>` + 右侧「复制」。
- ⋮ 菜单（右对齐弹窗，6 项）：`编辑事件` / `导出记录` / `清空记录` / `删除事件` / `统计` / `时间线`。

## 4. 新建/编辑事件弹层

- 模态窗居中：「新建事件」标题 + 输入框（placeholder `事件名称（如：喝水、吃药、打卡）`）+ 右下角字数 `0/20` + 「选择颜色」+ 12 色圆点色板 + 底部右侧「取消」/「保存」。
- 编辑既有事件时同弹层复用。

## 5. 统计页（StatsActivity）

- 顶栏标题「统计」。
- 两卡并排：`事件数`（大数字）/ `记录总数`（大数字）。
- 「记录最多的事件」卡：`e7 · 共 2 条`。
- 「各事件记录数」柱状图：每根柱顶部标数值、柱下标事件名（11 根 = 11 事件）。
- 「近 14 天记录趋势」柱状图：横轴日期号（2~15），柱顶标数值，只标有数据的日号。

## 6. 设置页（SettingsActivity）

- 标题「设置」+ 返回。
- **事件排序** 区块：说明 + 单选 `手动排序` / `按最近记录`（蓝圆点选中）。
- **桌面小组件** 区块：说明（三种类型）+ 单选 `小组件圆角`：`小圆角 (8)` / `中圆角 (16)` / `大圆角 (24)` / `超大圆角 (32)`。
- **一键添加到桌面** 区块：说明 + 三个按钮（全部事件/单事件/胶囊）+ ⚠️ 黄色提示「这三个按钮不一定能用」（小米/真我等桌面未实现官方 pin 接口时仅给手动指引：长按桌面→小部件→找到时间戳记录→拖到桌面；单事件/胶囊拖入后弹「绑定事件」页）。
- 底部悬浮玻璃栏同主页。

## 7. 教程 / 关于

- 教程页：**WebView 加载 GitHub 文档** `github.com/baoru0908/timestamp-recorder#tutorial`（离线显示错误页）。
- 关于页：NestedScrollView + 玻璃栏（应用介绍/版本）。

## 8. 桌面小组件（三套）

| 组件 | 尺寸 | 布局 |
|---|---|---|
| 胶囊 | 2×1 | 事件色底圆角横条：左事件名(16sp bold 白, weight=1) + 「+」图标(22dp) + 「记录」(14sp bold 白, marginStart 6dp)；整卡点击即记录 |
| 单事件 | 1×1~4×4 | 事件色底：垂直居中「事件名(20sp bold 白, 最多2行) / 最近时间(13sp monospace 白60%) / 累计次数(12sp 白80%) / 点击记录提示(11sp 白70%)」；字号随格子尺寸动态开关，2×2 以上才有次数/提示 |
| 全部事件 | 2×2~4×4 | 标题行「时间戳记录」(15sp bold 白) + 右「点击记录」(10sp 白60%)；固定最多 6 行：每行 `●色点(10dp) + 事件名(白) + 右侧最近时间(白)`，行底中性半透明圆角、文字白字；2×2 时只显 4 行 |

- 单事件/胶囊添加时弹 **「绑定事件」** 配置页：标题 + 说明 + 事件列表（每行 `事件名 + 共 N 条记录`），点行即绑定。
- 全部事件无需绑定，直接渲染。

## 9. 鸿蒙版现有差异（P3 对齐清单 —— 已全部闭环，模拟器深浅色逐页实测）

1. **深浅色**：Android 跟随系统；鸿蒙版目前固定浅色 → **✅ P3 完成**：`util/Theme.ets` LIGHT/DARK 双语义色板 + 三段渐变，EntryAbility 跟随系统 COLOR_MODE_NOT_SET 并监听 onConfigurationUpdate，深浅色全页实测。
2. **玻璃效果**：Android 液态玻璃顶栏/底栏（折射+色散）；鸿蒙 → **✅ P3 完成**：半透明玻璃色板（glassCard/Stroke/Toolbar/Menu）+ 细描边近似液态玻璃；顶/底栏改 Stack 平级独立悬浮（铺满覆盖层会吞触摸，见 DEVELOPMENT #38）。
3. **胶囊组件缺「+」图标**：鸿蒙 CapsuleCard 只有「记录」文字 → **✅ P3 完成**：补 Text('+') 22 +「记录」14 bold 常显。
4. **单事件组件字体**：Android 时间用 `monospace`；鸿蒙未设 → **✅ P3 完成**：`fontFamily('monospace')`；并修名字被挤截断（Blank 撑空间，见 DEVELOPMENT #42）。
5. **详情页背景**：Android 为事件色渐变；鸿蒙 → **✅ P3 完成**：全局主题渐变底 + 事件色「记录此刻」大按钮，深浅色均实测。
6. **教程页**：Android WebView 加载 GitHub 文档；鸿蒙占位 toast → **✅ P3 完成**：`pages/Tutorial.ets` 用 Web 加载同一 URL，onErrorReceive 切内置离线兜底，实测加载成功。
7. **设置页小组件圆角四档**：Android 8/16/24/32 单选；鸿蒙 → **✅ P3 完成**：设置四档（选中蓝底、块自身圆角即预览）→ 写偏好 + syncAllForms 实时回刷卡片，8/32 逐档目视、默认 24。
8. **统计页卡片**：Android「事件数/记录总数」两卡并排大数字 → **✅ P3 完成**：蓝/绿两并排 + 整宽橙「记录最多事件」+ 事件色柱图 + 近 14 天趋势，深浅色实测。
9. **事件行记录按钮**：统一为 `+ N`（含累计次数）→ **✅ P3 完成**：主页事件行胶囊 `+ N` 实时递增实测。
10. **FAB 位置可切换**（左/中/右）→ **✅ 核对关闭**：通读 Android 源码，FAB 本就固定底部中央、并无左/中/右设置项，鸿蒙同样固定中央，无需对齐。
