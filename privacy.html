隐私政策

时间戳记录器（Timestamp Recorder）· 更新日期：2026-09-21

本隐私政策适用于「时间戳记录器」（包名 com.timestamp.recorder，以下简称"本应用"）。我们深知个人信息的重要性，并致力于保护你的隐私。本政策用通俗语言说明本应用如何处理你的数据。

1. 我们不收集任何个人信息

本应用不收集、不传输、不存储任何个人身份信息、位置信息、通讯录、相册、设备标识（如 OAID/IMEI）等数据。应用内没有任何账号体系、没有云同步、没有行为统计。

2. 已收集个人信息清单

依据相关法律法规要求，我们以清单形式列明本应用收集的个人信息：

个人信息项收集目的收集方式使用范围
无———

需要说明的是，你创建的事件名称、事件颜色，以及每一次记录的时间戳，属于你自己的本地数据，仅保存在你的设备中，我们不会读取、上传、收集或共享。

3. 第三方共享个人信息清单

共享对象共享信息项共享目的共享方式
无———

本应用未接入任何第三方 SDK，不存在向任何第三方共享、转让、公开披露或出售个人信息的行为，也不存在个人信息出境情形。

4. 数据完全存储在本地

你创建的事件（如"喝水""吃药""打卡"）和每一次记录的时间戳，仅保存在你设备的应用沙箱私有存储中，不会上传到任何服务器。本应用不参与系统的数据备份与恢复，换机迁移请通过「设置 → 数据备份 → 导出 JSON」自行完成；卸载应用会删除这些数据。

5. 不申请任何权限

本应用为纯本地工具，不申请网络、存储、相机、位置等任何敏感权限。桌面卡片为系统服务卡片能力，仅用于在桌面展示你的事件信息并提供点击记录，不涉及个人信息收集。

6. 无第三方 SDK

本应用不含任何广告、统计、推送等第三方 SDK，不存在数据共享、出售或跨境传输行为。

7. 你的数据控制权

  • 随时可删除单个事件、单条记录或全部数据；
  • 支持一键导出全部数据为 JSON 备份文件；
  • 卸载应用即彻底清除本地数据。

8. 你的权利与行使方式

  • 撤回同意：进入「设置 → 隐私 → 撤回隐私同意」即可撤回你对本隐私政策的同意。撤回后本应用会重新展示本政策并再次征得你的同意；撤回不影响撤回前基于你的同意已进行的处理。
  • 查询与更正：你可在应用内直接查看、修改事件名称与颜色。
  • 删除：可删除单个事件、单条记录，或在设置中清除全部数据；卸载应用将彻底删除本地数据。
  • 导出：进入「设置 → 数据备份 → 导出备份」，可将全部数据导出为 JSON 文件。
  • 注销账号：本应用无账号体系，不涉及账号注册与注销。

9. 未成年人保护

本应用不涉及任何用户注册与内容提交，对未成年人同样无任何信息收集行为。

10. 政策更新

如本政策发生变化，我们将在此页面与应用内同时更新并标注新的生效日期，并在版本更新后重新征得你的同意。
